Compare all four, same input

Feeds the exact same text to all four stable APIs and times two things separately for each: setting up the session/instance (create()) and the actual task call. Not a perfectly fair comparison — the four APIs do genuinely different jobs (chat vs. summarize vs. translate vs. classify) — but the input is identical, so relative setup and processing cost are directly comparable. Run it twice: the first run pays for a cold session; a second run (same page load) shows the warm cost.

Concurrency test

Fires multiple calls at once via Promise.all and records each one's real start/end time relative to a shared zero point. If two calls' time windows overlap, they ran in parallel; if the second only starts once the first ends, they were serialized.

All four different APIs, at once

This is the one that actually answers whether they share a single underlying inference slot. Each API's concurrent finish time is compared against its own solo baseline, not an aggregate — a sharper test than just checking the overall total. One real limitation to know before trusting a single run: the call order is randomized each time, but whichever API happens to go first in a given run always looks "independent" if there's one shared queue underneath — it's not proof, it's a first-mover artifact. Run it a few times: if the same API(s) stay independent no matter where they land in the shuffle, that's real independence; if it rotates run to run, that's a shared, contended resource.
