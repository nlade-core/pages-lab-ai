Webcam + Gemini Nano

Point your camera at something. Chrome's on-device Gemini Nano describes each frame, one at a time.

Not real-time video understanding — the Prompt API only accepts single still images, not a video stream. This grabs one frame, waits for the model to finish describing it, then grabs the next. Expect a caption every second or two, not 30fps captioning. Everything runs on-device: the camera feed never leaves your machine, nothing is uploaded anywhere. Chrome desktop only.
