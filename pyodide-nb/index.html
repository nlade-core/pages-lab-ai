pages-lab-ai

A minimal Jupyter-style notebook — write Python in cells, run them, see the output. Every cell shares the same running interpreter, so a variable set in one cell is still there in the next. Runs entirely via Pyodide, client-side.

Eighth page in the pages-lab-ai family, alongside the image classifier, semantic search, chat, speech to text, text to speech, Chrome's built-in AI, and code chat. Standalone for now, built to be the code-execution tool a future chatbot can call. Source.

Loads Pyodide (plain Python, no extra packages) — about 11MB, cached by your browser after the first visit. Nothing downloads until you click.

100% client-side. No upload, no server, no account. Part of the pages-lab family of experiments.
