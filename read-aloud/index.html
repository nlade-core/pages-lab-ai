Read Aloud

Type something. Your browser reads it back out loud — no model, no download, built into the browser already.

This is the Web Speech API's speechSynthesis — not related to Gemini Nano, and a different thing entirely from this family's other text to speech page, which downloads and runs a real neural TTS model (Kokoro-82M) for higher-quality voices. This one just asks the operating system to speak, instantly, using whatever voices are already installed. Some voices run entirely on-device; some are marked "network" below and require one.
