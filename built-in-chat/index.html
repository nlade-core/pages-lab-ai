Built-in model chat

One page, whichever model your browser ships. Chrome gives you Google's Gemini Nano, Edge gives you Microsoft's Phi-4-mini. The page detects which one and uses it. Nothing leaves your device.

Both browsers expose their model through the same Prompt API, so this code doesn't change between them. Part of pages-lab-ai. Source.
