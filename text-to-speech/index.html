pages-lab-ai

Kokoro — an 82M-parameter text-to-speech model, running entirely in your browser. Type something, pick a voice, hear it read aloud. No server, nothing sent anywhere.

Fifth page in the pages-lab-ai family, alongside the image classifier, semantic search, chat, speech to text — this one's the mirror image of that last one — and Chrome's built-in AI. Runs on Kokoro via kokoro-js. Source.

Heads up if you're on Safari: generating speech can spike CPU/memory and appear to hang — this is a known WebKit JIT bug in ONNX Runtime Web's JSEP mode (onnxruntime#26827), not a bug in this page. It's not guaranteed to happen every time, but if it does, Chrome or Edge don't have this issue.

Loads Kokoro (int8-quantized) — about 92MB, cached by your browser after the first visit. Nothing downloads until you click.
