Video + Gemini Nano

Upload a video clip. Chrome's on-device Gemini Nano describes one frame per second and builds a timestamped transcript.

Frame-by-frame, not real video understanding: the Prompt API only accepts single still images, so this samples one frame per second of the clip and analyzes each independently -- a 90-second video means 90 separate model calls, run one at a time, not in parallel. Everything runs on-device: the file never leaves your machine, nothing is uploaded anywhere. Chrome desktop only. Part of pages-lab-ai — source.
