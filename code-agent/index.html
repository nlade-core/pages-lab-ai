A chatbot that can actually run Python to check its own answers. Gemini Nano decides, on its own, when to call a real code-execution tool — writes the code, waits for the real result, reads it back — before giving you a final answer. No fake tool use: every "ran code" step below is genuinely executed by Pyodide in your browser.

Tenth page in the pages-lab-ai family, alongside the image classifier, semantic search, chat, speech to text, text to speech, Chrome's built-in AI, code chat, a Pyodide notebook, thinking chat, and chat threads. The tool-use loop that page 8's notebook and page 9's structured output were both built toward. Chrome desktop only. Source.
