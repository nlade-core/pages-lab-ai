pages-lab-ai

A real large language model — streaming responses, generated entirely in your browser via WebGPU. No server, no API key, nothing sent anywhere.

Third page in the pages-lab-ai family, alongside the image classifier, semantic search, speech to text, text to speech, Chrome's built-in AI, code chat, a Pyodide notebook, thinking chat, code agent, chat threads, and zero-shot classification. Runs on WebLLM (MLC-LLM). Source.

This demo needs WebGPU, which your current browser doesn't support (or it's disabled).

Unlike the other two pages here, there's no CPU fallback for this one — running an LLM this way genuinely needs GPU acceleration. Try Chrome or Edge on desktop, or Safari 18+.

Pick a size. Bigger models are slower to download and need more GPU memory, but reply more coherently.

100% client-side. No upload, no server, no account. Part of the pages-lab family of experiments.
